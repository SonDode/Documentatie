\chapter*{Abstract}

\textbf{Type of thesis:} synthesis and applied research

\vspace{1em}

This thesis describes the process of designing and building the
\textbf{Gym-Connect} web application, a tool aimed at athletes who
practice strength training and want to track their progress in a
structured way. The idea started from a real frustration: most
similar applications on the market are either too complicated or
charge money for basic features. Gym-Connect aims to be different --
free, simple and directly accessible from the browser, without
installation.

From a technical standpoint, the project pursues four main objectives:
building a functional client-server architecture in which the React
frontend communicates with an Express server through authenticated
HTTP requests; implementing user authentication through Clerk;
developing a real-time workout logging module, with support for
weight calculation and intensity indicators such as RIR and
estimated 1RM; and, last but not least, building a progress analysis
module that uses linear regression to estimate short-term evolution
and automatically detect performance plateaus.

The thesis is organized into six chapters. The first two establish
the context -- why this problem exists and what solutions are already
available on the market. The next two go into the technical details
of the proposed solution. The last two present the application
concretely, as it actually looks and works, and draw the conclusions.

\vspace{1em}
\noindent\textbf{Keywords:} web application, strength training,
progressive overload, React, TypeScript, Express.js, Prisma,
PostgreSQL, Clerk, progress analysis, 1RM, RIR.
